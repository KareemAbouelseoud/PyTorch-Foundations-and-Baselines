# PyTorch Foundations & Deep Dive

A structured, bottom-up implementation of PyTorch core primitives, tensor operations, and custom training loops. 

This repository serves as a foundational engineering deep dive in preparation for my transition into research.

## Motivation & Background

Coming from a strong **TensorFlow** background in my studies, I already use PyTorch in my day-to-day professional work. However, utilizing high-level framework wrappers in production is very different from understanding the underlying calculus and gradient flow. 

I created this repository to strip away the abstractions. The goal is to build a rigorous, intuitive understanding of multidimensional tensor mechanics, custom `autograd` implementations, and raw optimization loops—skills strictly necessary for building custom Reinforcement Learning architectures and hybrid World Models.

*(Note: To ensure complete conceptual mastery over the underlying mathematics and C++ backend behaviors, this repository is 100% hand-coded without the use of LLM coding agents.)*
