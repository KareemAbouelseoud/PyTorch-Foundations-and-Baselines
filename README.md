# PyTorch Foundations & Deep Dive

A structured, bottom-up implementation of PyTorch core primitives, tensor operations, and custom training loops. 

This repository serves as a foundational deep dive in preparation for my journey in research.

## 🧠 Motivation & Background

Coming from a strong **TensorFlow** background in my studies, I already use PyTorch in my day-to-day professional work as an LLM Engineer. However, utilizing high-level framework wrappers in production is very different from understanding the underlying calculus and gradient flow. 

I created this repository to strip away the abstractions. The goal is to build a rigorous, intuitive understanding of multidimensional tensor mechanics, custom `autograd` implementations, and raw optimization loops, skills necessary for custom Reinforcement Learning architectures and hybrid World Models, and LLMs and also begin learning JAX as well.

Coding Agents are not and will never be used here, and I enable text completion when writing something I already have learned and written before.
